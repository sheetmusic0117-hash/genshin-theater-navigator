# 劇詩導航 · Theater Navigator

原神「幻想真境劇詩」（月諭／卓越）規劃工具：整理角色池、當期資料，逐幕規劃事件、邀請、祝福、神秘收穫、出戰隊伍與幻劇之花，最後產生待辦清單。

A planner for Genshin Impact's **Imaginarium Theater** (Lunar / Visionary): build your roster, enter the season's data, then plan each act's events, invites, blessings, mystery rewards, teams and flowers.

原神「幻想シアター」（月諭／卓越）の計画ツール。

## 使用方式

直接開啟網頁即可，不需安裝、不需登入。資料存在瀏覽器（localStorage），可用「匯出全部／匯入全部」備份或換電腦。

規則整理見 [RULES.md](RULES.md)。

## 更新角色資料

```
python tools/update_characters.py
```
